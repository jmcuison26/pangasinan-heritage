Level 1

Atoms

Atoms are the smallest, indivisible UI building blocks. They cannot be broken down further without losing their purpose.

Atom 1

Button

📁 components/atoms/BaseButton.vue

1. Visual Preview
2. Usage Context

The Button atom is the foundational interactive element used for all CTAs across the platform. Primary is used for main actions (e.g., "Explore Now", "Plan Your Visit"). Secondary is used for supporting actions on cards ("Learn More"). Ghost is used for low-priority utility actions ("Clear Search"). The href prop automatically renders it as an <a> tag when a link is needed.

3. Responsive Logic
BreakpointBehavior
Mobile (< sm)Full width inside mobile nav drawer; inline otherwise
Tablet (sm+)Inline-flex with auto width
All sizesMinimum 44×44px touch target (WCAG 2.5.5)

Size is controlled via the size prop: sm for cards/nav, md for standard CTAs, lg for hero sections.

4. Code Reference 
<template>
  <component
    :is="href ? 'a' : 'button'"
    :href="href"
    :type="href ? undefined : type"
    :disabled="disabled"
    :class="[
      'inline-flex items-center justify-center font-semibold rounded-full transition-colors',
      sizeClasses, variantClasses,
      { 'opacity-50 cursor-not-allowed': disabled }
    ]"
  >
    <slot />
  </component>
</template>

<script setup lang="ts">
const props = withDefaults(defineProps<{
  variant?: 'primary' | 'secondary' | 'ghost'
  size?:    'sm' | 'md' | 'lg'
  disabled?: boolean
  href?:    string
}>(), { variant: 'primary', size: 'md', disabled: false })

const variantClasses = computed(() => ({
  primary:   'bg-teal-600 text-white hover:bg-teal-500',
  secondary: 'bg-white text-teal-600 border border-teal-600',
  ghost:     'bg-transparent text-teal-600 hover:bg-teal-50',
}[props.variant]))

const sizeClasses = computed(() => ({
  sm: 'text-sm px-4 py-1.5',
  md: 'text-base px-6 py-2.5',
  lg: 'text-lg px-8 py-3',
}[props.size]))
</script>
Atom 2

Typography

📁 components/atoms/BaseTypography.vue

1. Visual Preview
OVERLINE LABEL
H1 — Hero Heading
H2 — Section Title
H3 — Sub-section
H4 — Card Title
Body — Paragraph text used for descriptions and content sections with relaxed line height for readability.
Caption — Supporting text used inside cards and beneath images.
2. Usage Context

The Typography atom enforces a consistent typographic scale across all pages. It prevents ad-hoc Tailwind text classes, ensuring visual consistency. Used in hero headings, section labels, card titles, body paragraphs, and captions throughout the platform.

3. Responsive Logic
VariantMobileDesktop
h1text-4xlmd:text-6xl
h2text-3xlmd:text-4xl
h3–captionFixed size — no breakpoint change
4. Code Reference 
<template>
  <component :is="tag"
    :class="[typeClasses, colorClasses]">
    <slot />
  </component>
</template>

<script setup lang="ts">
const props = withDefaults(defineProps<{
  variant?: 'h1'|'h2'|'h3'|'h4'|'body'|'caption'|'overline'
  color?:   'default'|'muted'|'primary'|'white'
  tag?:     string
}>(), { variant: 'body', color: 'default' })

const typeClasses = computed(() => ({
  h1:      'text-4xl md:text-6xl font-bold leading-tight tracking-tight',
  h2:      'text-3xl md:text-4xl font-bold leading-snug',
  h3:      'text-2xl font-semibold leading-snug',
  h4:      'text-xl font-semibold',
  body:    'text-base leading-relaxed',
  caption: 'text-sm leading-relaxed',
  overline:'text-xs uppercase tracking-widest font-medium',
}[props.variant]))

const colorClasses = computed(() => ({
  default: 'text-gray-800',
  muted:   'text-gray-500',
  primary: 'text-teal-600',
  white:   'text-white',
}[props.color]))
</script>

2. Usage Context

The ColorToken atom is a documentation-only component used to display the platform's design token color palette. It is used exclusively in design system showcase pages, not in production pages. It communicates design tokens visually to developers and stakeholders.

3. Responsive Logic

Displayed in a flex-wrap row that wraps on small screens. Swatch size is fixed at w-16 h-16 — large enough to be visible on mobile. No breakpoint changes needed as this is a documentation component.

4. Code Reference

2. Usage Context

The Icon atom renders emoji icons with consistent sizing and accessibility behavior — without importing any external icon library, keeping the bundle size minimal for 3G/4G users. Used in navigation items, visit info cards, the heritage grid empty state, and hero sections.

3. Responsive Logic

Size is controlled via the size prop only — no breakpoint changes inside the component. The parent decides which size to use. When label is provided, aria-label is set (accessible). When decorative, aria-hidden="true" is applied automatically.

4. Code Reference 
<template>
  <span
    :class="['inline-flex items-center justify-center select-none', sizeClass]"
    :aria-label="label"
    :aria-hidden="!label"
    role="img"
  >
    {{ emoji }}
  </span>
</template>

<script setup lang="ts">
const props = withDefaults(defineProps<{
  emoji:  string
  label?: string
  size?:  'sm' | 'md' | 'lg' | 'xl'
}>(), { size: 'md' })

const sizeClass = computed(() => ({
  sm: 'text-sm', md: 'text-xl',
  lg: 'text-3xl', xl: 'text-5xl',
}[props.size]))
</script>

Image

📁 components/atoms/BaseImage.vue

1. Visual Preview
🏝️
rounded="lg"
🌊

2. Usage Context

The Image atom wraps all content images in the platform — centralizing lazy loading, alt text enforcement, and border radius. Used for island thumbnails in cards (rounded="lg", lazy=true) and hero images (rounded="none", lazy=false). Any future image optimizations only need one change here.

3. Responsive Logic
PropertyBehavior
Widthw-full — fills parent container
Heighth-full — fills parent container height
Fitobject-cover — maintains aspect ratio, crops to fill
Loadinglazy by default; set lazy=false for hero images
4. Code Reference 
<template>
  <figure :class="['overflow-hidden', roundedClass]">
    <img
      :src="src"   :alt="alt"
      :width="width"   :height="height"
      :loading="lazy ? 'lazy' : 'eager'"
      :class="['w-full h-full object-cover', roundedClass]"
    />
    <figcaption v-if="caption"
      class="text-xs text-gray-400 mt-1 text-center">
      {{ caption }}
    </figcaption>
  </figure>
</template>

<script setup lang="ts">
const props = withDefaults(defineProps<{
  src:      string    // Image URL
  alt:      string    // Required alt text
  caption?: string    // Optional caption
  rounded?: 'none'|'sm'|'md'|'lg'|'full'
  lazy?:    boolean   // Native lazy loading
}>(), { rounded: 'md', lazy: true })
</script>

Molecules

Molecules are groups of two or more atoms that form a simple, reusable UI unit with a single clear purpose.

Molecule 1

Heritage Card

📁 components/molecules/HeritageCard.vue

⚛️ Uses: BaseTypography, BaseButton

1. Visual Preview
🏝️ ⭐ Most Popular
FEATURED ISLAND
Governor Island
The largest and most developed island with cottages and a panoramic viewing deck.
2. Usage Context

The Heritage Card molecule displays individual island previews in the Heritage Grid. Each card shows a thumbnail, category label, title, short description, and a Learn More button that triggers a modal. "The Heritage Card is used exclusively for displaying tourist site previews in a responsive heritage-site grid."

3. Responsive Logic
BreakpointGrid ColumnsCard Behavior
Mobile (< sm)1 columnFull width
Tablet (sm)2 columnsFull width in cell
Desktop (lg)3 columnsFull width in cell

Image height fixed at h-48 across all sizes. Description clamped to 2 lines via line-clamp-2 to keep equal card heights.

4. Code Reference 
<template>
  <article class="bg-white rounded-2xl shadow-sm overflow-hidden
             hover:shadow-md transition-shadow">
    <!-- Image -->
    <div class="relative h-48 overflow-hidden"
         style="background-color:#ccfbf1">
      <img v-if="image" :src="image" :alt="title"
           loading="lazy" class="w-full h-full object-cover" />

        class="absolute top-3 left-3 bg-teal-600 text-white
               text-xs font-semibold px-3 py-1 rounded-full">

📁 components/molecules/SearchForm.vue

⚛️ Uses: BaseButton, BaseIcon

1. Visual Preview
Desktop (side by side):

Mobile (stacked):

2. Usage Context

The Search Form molecule is used at the top of the Heritage Grid organism to allow users to filter islands by name or description. It emits a search event with the typed query — all filtering logic lives in the parent. "The Search Form is used exclusively as an inline filter for the Heritage Grid — not as a global site search."

3. Responsive Logic
BreakpointLayout
Mobile (< sm)Stacked — input full-width on top, button below
Tablet+ (sm+)Side by side — input flex-1, button inline
4. Code Reference 
<template>
  <form role="search"
    class="flex flex-col sm:flex-row gap-3 w-full"
    @submit.prevent="onSubmit">
    <label :for="inputId" class="sr-only">
      {{ placeholder }}
    </label>
    <input :id="inputId" v-model="query"
      type="search" :placeholder="placeholder"
      class="flex-1 px-5 py-3 rounded-full border border-gray-300
             focus:ring-2 focus:ring-teal-500" />
    <BaseButton type="submit" variant="primary">
      <BaseIcon emoji="🔍" size="sm" />
      <span class="ml-2">Search</span>
    </BaseButton>
  </form>
</template>

<script setup lang="ts">
const emit = defineEmits<{ search: [query: string] }>()
const query = ref('')
const inputId = `search-${Math.random().toString(36).slice(2,7)}`
function onSubmit() { emit('search', query.value.trim()) }
</script>
Molecule 3

Navigation Item

📁 components/molecules/NavigationItem.vue

⚛️ Uses: BaseIcon

1. Visual Preview
🏠 Home
ℹ️ About (hover)
🗺️ Islands (active)
📅 Visit
2. Usage Context

The Navigation Item molecule renders individual nav links inside the Header Navigation organism. It auto-detects the current route and applies an active style. It renders as a NuxtLink with aria-current="page" when active for screen reader accessibility.

3. Responsive Logic
BreakpointBehavior
Mobile (< md)Stacked vertically inside mobile drawer
Desktop (md+)Horizontal inline row inside header

The component is layout-agnostic — it is always a <li> element. The parent HeaderNavigation controls orientation.

4. Code Reference 
<template>
  <li>
    <NuxtLink :to="to"
      :aria-current="isActive ? 'page' : undefined"
      :class="[
        'flex items-center gap-2 px-4 py-2 rounded-lg font-medium transition-colors',
        'focus:outline-none focus:ring-2 focus:ring-teal-500',
        isActive
          ? 'bg-teal-50 text-teal-700'
          : 'text-gray-600 hover:bg-gray-100 hover:text-gray-900'
      ]">
      <BaseIcon v-if="icon" :emoji="icon"
        size="sm" aria-hidden="true" />
      <span>{{ label }}</span>
    </NuxtLink>
  </li>
</template>

<script setup lang="ts">
const props = defineProps<{
  label: string
  to:    string
  icon?: string
}>()
const route = useRoute()
const isActive = computed(() => route.path === props.to)
</script>

Organisms are complex, self-contained UI sections composed of molecules and atoms. They form distinct sections of a page.

Organism 1

Heritage Grid

📁 components/organisms/HeritageGrid.vue

🧬 Uses: HeritageCard, SearchForm + BaseTypography, BaseIcon, BaseButton

1. Visual Preview
DISCOVER THE ISLANDS
Island Highlights
Explore the most iconic islands within Hundred Islands National Park.
🔍 Search heritage sites...
🏝️
Governor Island
🐚
Children's Island
⛺
Quezon Island
2. Usage Context

The Heritage Grid is the main island discovery interface on the homepage. It combines a section header, a SearchForm for live filtering, and a responsive grid of HeritageCard molecules. It manages its own search state internally and emits a learn-more event when a card is clicked, which the parent page uses to open the Island Modal.

3. Responsive Logic
BreakpointGrid Columns
Mobile (< sm)1 column
Tablet (sm)2 columns
Desktop (lg+)3 columns

Uses Tailwind: grid-cols-1 sm:grid-cols-2 lg:grid-cols-3. Search filtering is reactive — the filteredItems computed property updates on every keystroke. An empty state with a clear button is shown when no results match.

4. Code Reference 
<template>
  <section :aria-labelledby="headingId" class="py-12 px-4">
    <div class="max-w-6xl mx-auto">
      <!-- Header using Atoms -->
      <BaseTypography variant="overline" color="primary">Discover the Islands</BaseTypography>
      <BaseTypography :id="headingId" variant="h2">{{ title }}</BaseTypography>

      <!-- Search Molecule -->
      <SearchForm @search="onSearch" />

      <!-- Grid of Card Molecules -->
      <div v-if="filteredItems.length"
        class="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-6">
        <HeritageCard v-for="item in filteredItems"
          :key="item.title" v-bind="item"
          @learn-more="$emit('learn-more', item)" />
      </div>

      <!-- Empty State -->
      <div v-else class="text-center py-16">
        <BaseIcon emoji="🔎" size="xl" />
        <BaseButton variant="ghost" @click="searchQuery = ''">
          Clear search
        </BaseButton>
      </div>
    </div>
  </section>
</template>

<script setup lang="ts">
const props = withDefaults(defineProps<{
  title?: string; items: HeritageItem[]
}>(), { title: 'Island Highlights' })

defineEmits<{ 'learn-more': [item: HeritageItem] }>()
const searchQuery = ref('')
const filteredItems = computed(() =>
  props.items.filter(i =>
    i.title.toLowerCase().includes(searchQuery.value.toLowerCase())
  )
)
</script>

2. Usage Context

The Header Navigation is the global site header placed on every page via layouts/default.vue. It provides brand identity, primary navigation, a CTA button, and a responsive hamburger menu for mobile. It is sticky with a frosted glass effect so it remains readable over page content while scrolling.

3. Responsive Logic
BreakpointBehavior
Mobile (< md)Logo + hamburger only; nav links hidden in drawer
Desktop (md+)Full horizontal nav with all links and CTA visible

Uses v-show on the mobile menu so the DOM is always present for accessibility. aria-expanded and aria-controls are set on the toggle button for screen readers.

4. Code Reference 
<template>
  <header class="sticky top-0 z-50 bg-white/90 backdrop-blur-sm
              border-b border-gray-100 shadow-sm">
    <div class="max-w-6xl mx-auto px-4 h-16
             flex items-center justify-between">

      <!-- Logo (BaseIcon atom) -->
      <NuxtLink to="/">
        <BaseIcon emoji="🏝️" size="md" />
        <span>Hundred Islands</span>
      </NuxtLink>

      <!-- Desktop nav (NavigationItem molecules) -->
      <nav class="hidden md:block">
        <ul class="flex items-center gap-1">
          <NavigationItem v-for="item in navItems"
            v-bind="item" :key="item.to" />
        </ul>
      </nav>

      <!-- CTA (BaseButton atom) -->
      <BaseButton variant="primary" size="sm"
        class="hidden sm:inline-flex">
        Plan Your Visit
      </BaseButton>

      <!-- Mobile toggle -->
      <button class="md:hidden"
        :aria-expanded="menuOpen"
        aria-controls="mobile-menu"
        @click="menuOpen = !menuOpen">
        {{ menuOpen ? '✕' : '☰' }}
      </button>
    </div>

    <!-- Mobile drawer -->
    <nav v-show="menuOpen" id="mobile-menu"
      class="md:hidden bg-white px-4 pb-4">
      <NavigationItem v-for="item in navItems"
        v-bind="item" />
    </nav>
  </header>
</template>

<script setup lang="ts">
const menuOpen = ref(false)
const navItems = [
  { label: 'Home',    to: '/',        icon: '🏠' },
  { label: 'About',   to: '/#about',  icon: 'ℹ️'  },
  { label: 'Islands', to: '/islands', icon: '🗺️' },
  { label: 'Visit',   to: '/#visit',  icon: '📅' },
]
</script>
